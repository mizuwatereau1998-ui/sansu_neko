# ねこねこ かけ算パズル 🐾

小学3年生向けに、猫の隊列をうごかして「かけ算のきまり」を確かめる、全3ステージの操作検証用プロトタイプです。添付のHTML試作版の学習内容・ハンドル操作をもとに、SVGの猫、連続アニメーション、クリア演出を作り直しています。

## あそび方

`index.html` をブラウザで開くだけで遊べます。インストール・サーバー・外部API・通信は不要です。GitHub Pagesでは、このフォルダーを公開対象に指定してください。

1. **ならべかえ**：黄色の ↔ ハンドルを右へドラッグ。7行 × 4列の28匹が、くるっと回って4行 × 7列になります。途中で戻すこともできます。手を離すと近い形にスナップします。
2. **ふたつに分ける**：緑の ↕ ハンドル、または点線を上下にドラッグ。上3行・下4行に分けます。グループの色、行数、匹数、式が一緒に変わります。
3. **くふうして計算**：48匹を上10行・下2行に分けます。40匹と8匹を色で対応づけ、クリア画面で `12×4 → 10×4＋2×4 → 40＋8 → 48` を順に表示します。

- 正解はドラッグ終了時に判定します。不正解のペナルティや制限時間はありません。
- 「やりなおす」でそのステージの初期状態に戻れます。「ヒント」で考える手がかりを表示します。
- 上部のステージ番号から自由に選べます。通常はクリア画面の「つぎのステージへ」で進みます。
- クリア画面を閉じても、広場の「クリアをみる」から再表示できます。
- マウス・指・ペンは共通のPointer Eventsで処理します。ハンドルにフォーカスして矢印キーでも操作できます。左右は回転、上下は分割。Home / Endは両端です。
- 音は初期OFF。右上の ♪ からONにすると、ブラウザ内で生成した短い効果音が鳴ります。
- OSの「視差効果を減らす」設定では、移動や紙吹雪のアニメーションを抑えます。

## ファイル構成

| ファイル          | 内容                                                             |
| ----------------- | ---------------------------------------------------------------- |
| `index.html`      | ゲーム画面、SVGの描画領域、クリア・結果ダイアログ                |
| `style.css`       | レスポンシブデザイン、色分け、演出                               |
| `game.js`         | ステージ設定、Pointer Events、座標計算、アニメーション、判定、音 |
| `assets/cat.js`   | 48×48座標で描画する猫のSVG。イラストに差し替える窓口             |
| `tests/smoke.cjs` | PlaywrightによるPC・タッチの主要操作確認                         |

`tests/interaction.cjs` は操作キャンセルや回転中の間隔などを追加確認します。

`game.js` 冒頭の `stages` に初期行数・列数、目標分割位置、ミッション、ヒントをまとめています。現状は指定された4列の3ステージ用に描画を調整しているため、別の列数や回転形式を追加するときは `layout()` の対応も必要です。

猫の総数ぶんのSVG要素を最初に作り、操作中には作り直しません。回転では角度を滑らかに変え、猫の間隔を一定に保ちます。分割では座標を補間し、requestAnimationFrameで歩くように移動します。猫の絵だけは回転させず、顔を見やすく保ちます。

## 動作確認

アプリ自体には依存パッケージがありません。自動確認のみ、Node.js・Playwright・Chromiumを使います。

```sh
# ターミナル1：リポジトリのルートで起動
python3 -m http.server 8000

# ターミナル2：Playwrightが利用できる環境で実行
node tests/smoke.cjs
node tests/interaction.cjs
```

Chromiumが標準の場所にない場合は `CHROMIUM_PATH` を指定します。Playwrightが未導入なら、検証用の別フォルダーに導入し、その `node_modules` を `NODE_PATH` に指定できます。スクリーンショットは一時フォルダー、または `ARTIFACT_DIR` に保存します。

自動確認では、1280px幅のマウスと390px幅のタッチ入力で、全3ステージの正解、不正解の分割、猫の総数、式、次へ進む操作、結果画面、リセット、ヒント、キーボード、横はみ出し、JavaScriptエラーを確認します。実機のiPhone/iPadやSafariでの確認は別途必要です。`interaction.cjs` では回転中の猫同士の間隔、操作キャンセル、判定待ち中のリセット、クリアの再表示、分割線そのもののドラッグを追加確認します。

このクラウド環境の管理ブラウザは `file://` をポリシーで禁止しているため、HTMLの直接起動だけはここでは検証できていません。通常のスクリプトだけで構成し、HTTP経由での全ステージ動作は確認しています。

## 次に検証したいこと

- 子どもが説明なしでハンドルを見つけ、回転・分割を試せるか。
- 並べ替えの前後で「何が変わり、何が変わらないか」を言葉にできるか。
- 小さい画面での48匹の数えやすさ。拡大表示や行の強調が必要か。
- 「10行に分ける」発見の段階では、10のまとまりをどう自然に気づかせるか。
- 操作に慣れた後、目標を示さずに自由に分けて式を見つける探索モード。

学習効果と操作の楽しさは、対象年齢の子どもによるプレイ観察で検証する想定です。進行状況の永続保存・スコア・外部通信は実装していません。

## GitHub Pagesで公開する

GitHubのリポジトリで **Settings → Pages → Build and deployment** を開きます。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

**Save** を押すと、GitHub側のデプロイ完了後に次のURLで遊べます。

https://mizuwatereau1998-ui.github.io/sansu_neko/

公開後は `main` に変更をpushすると更新されます。アプリ本体は静的なファイルだけで動作し、ビルド処理やAPIキーは不要です。
